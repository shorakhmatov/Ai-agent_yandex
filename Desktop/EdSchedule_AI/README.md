# EdSchedule AI — Интеллектуальная платформа управления расписанием

Полноценная SaaS-платформа для автоматического составления, оптимизации, проверки и публикации учебного расписания для школ, колледжей и университетов.

## 🚀 Ключевые возможности

1. **Ядро оптимизации (Google OR-Tools CP-SAT):**
   - Строгий учет жестких ограничений (нет накладок у преподавателей, групп и аудиторий, соответствие вместимости).
   - Оптимизация мягких ограничений (минимизация окон, равномерность нагрузки).
   - Автоматическое выявление и объяснение конфликтов.
2. **Кабинет заместителя директора (Vice Principal):**
   - Интерактивный мастер создания расписания (5 шагов).
   - Календарная сетка занятий с подсветкой конфликтов.
   - Управление версиями (Черновики, Сравнение, Публикация).
3. **Двуязычный интерфейс (Русский и Узбекский):**
   - Полная локализация интерфейса (`ru` / `uz`).
   - Поддержка символов узбекской латиницы (`Oʻ`, `Gʻ`).
4. **Интерактивный ИИ-помощник (Tool Calling):**
   - Безопасные вызовы инструментов сервера (`get_available_rooms`, `find_schedule_conflicts`, `get_teacher_workload`, `get_schedule`).
   - Понимание естественного языка на русском и узбекском.
5. **Экспорт данных:**
   - PDF, Excel/CSV, календарный формат iCalendar (ICS).
6. **Безопасность и изоляция данных:**
   - Tenant Isolation Middleware (`organization_id`).
   - Ролевая модель доступа (RBAC) на уровне каждого запроса.

---

## 🛠 Технологический стек

- **Backend:** Python 3.12, Django 5.x, Django REST Framework, SimpleJWT, Google OR-Tools CP-SAT, MySQL 8.4 LTS, ReportLab, ics.
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons.

## 💻 Локальный запуск

### 1. Бэкенд (Django)
```bash
# Перейдите в корень проекта
python -m venv venv
# Активация окружения (Windows):
.\venv\Scripts\activate

# Установка зависимостей:
pip install -r requirements.txt

# Применение миграций:
python manage.py migrate

# Запуск сервера разработки:
python manage.py runserver
```

### 2. Фронтенд (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
Фронтенд будет доступен по адресу: `http://localhost:5173`.

---

## 🐳 Запуск через Docker Compose

```bash
docker-compose up --build
```
Бэкенд запустится с базой данных MySQL 8.4 и Redis.
